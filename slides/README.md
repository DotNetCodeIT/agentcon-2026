# Speaker slides

Drop decks for each session here. Supported local formats: **PDF** (recommended,
viewable inline) and **PPTX/PPT/ODP** (rendered through the Office Online viewer).
Then list them in [`../data/slides.json`](../data/slides.json) so they appear on the site.

Each entry can point to **either**:

- a local file in this folder (`"file": "slides/my-talk.pdf"`), and/or
- an external URL (`"url": "https://speakerdeck.com/..."`).

If both are set, the local file is the primary "View"/"Download" target and the
URL becomes a "View online" link.

## First-slide preview

A first-page thumbnail is rendered automatically. The site looks for:

1. `preview` field in the JSON entry (any image URL), then
2. `slides/previews/<stem>.png` (auto-generated by CI from your PDF/PPTX), then
3. a fallback gradient badge with the file extension.

See [`previews/README.md`](previews/README.md) for details.

## In-page viewer

Clicking the thumbnail or the **View** button opens a modal:

- PDF → embedded directly in an `<iframe>`.
- PPTX/PPT/ODP → embedded via `view.officeapps.live.com` (requires the file to be
  publicly reachable, which is the case for GitHub Pages).

## Example entry

```json
{
  "title": "Build and launch AI Agents fast with Microsoft Foundry Toolkit for VS Code",
  "speaker": "Carlotta Castelluccio",
  "file": "slides/foundry-toolkit.pdf",
  "url": "",
  "preview": "",
  "description": "Optional one-line description.",
  "tags": ["foundry", "vs-code"]
}
```

Filenames may use any characters — they will be URL-encoded automatically.
